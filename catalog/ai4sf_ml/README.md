# Field boundaries for Cambodia and Vietnam (AI4SmallFarms) with splits: benchmark collections

Fields of the World benchmark chips cut from the harmonized field boundary collection [Field boundaries for Cambodia and Vietnam (AI4SmallFarms) with splits](https://source.coop/ftw/harmonized-field-data/ai4sf_ml), one collection per year. Each collection has its own README with what its chips, masks and imagery contain. Open this group in the [data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/benchmark-data/ai4sf_ml/catalog.json) or go back to the [catalog](https://source.coop/ftw/benchmark-data).
