# Field boundaries for Lithuania - Eurocrops 2021: benchmark collections

Fields of the World benchmark chips cut from the harmonized field boundary collection [Field boundaries for Lithuania - Eurocrops 2021](https://source.coop/ftw/harmonized-field-data/ec_lt), one collection per year. Each collection has its own README with what its chips, masks and imagery contain. Open this group in the [data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/benchmark-data/ec_lt/catalog.json) or go back to the [catalog](https://source.coop/ftw/benchmark-data).
