# Mapping Africa: crop field boundary labels for Africa, 2017-2023: benchmark collections

Fields of the World benchmark chips cut from the harmonized field boundary collection [Mapping Africa: crop field boundary labels for Africa, 2017-2023](https://source.coop/ftw/harmonized-field-data/lacuna), one collection per year. Each collection has its own README with what its chips, masks and imagery contain. Open this group in the [data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/benchmark-data/lacuna/catalog.json) or go back to the [catalog](https://source.coop/ftw/benchmark-data).
