# Italy Tuscany (ITI1) Crop Fields — EuroCropsV2: benchmark collections

Fields of the World benchmark chips cut from the harmonized field boundary collection [Italy Tuscany (ITI1) Crop Fields — EuroCropsV2](https://source.coop/ftw/harmonized-field-data/it_1), one collection per year. Each collection has its own README with what its chips, masks and imagery contain. Open this group in the [data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/benchmark-data/it_1/catalog.json) or go back to the [catalog](https://source.coop/ftw/benchmark-data).
