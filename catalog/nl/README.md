# BRP Crop Field Boundaries for The Netherlands (CAP-based): benchmark collections

Fields of the World benchmark chips cut from the harmonized field boundary collection [BRP Crop Field Boundaries for The Netherlands (CAP-based)](https://source.coop/ftw/harmonized-field-data/nl), one collection per year. Each collection has its own README with what its chips, masks and imagery contain. Open this group in the [data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/benchmark-data/nl/catalog.json) or go back to the [catalog](https://source.coop/ftw/benchmark-data).
