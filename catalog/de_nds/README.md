# Crop Fields for Lower Saxony / Bremen / Hamburg, Germany: benchmark collections

Fields of the World benchmark chips cut from the harmonized field boundary collection [Crop Fields for Lower Saxony / Bremen / Hamburg, Germany](https://source.coop/ftw/harmonized-field-data/de_nds), one collection per year. Each collection has its own README with what its chips, masks and imagery contain. Open this group in the [data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/benchmark-data/de_nds/catalog.json) or go back to the [catalog](https://source.coop/ftw/benchmark-data).
